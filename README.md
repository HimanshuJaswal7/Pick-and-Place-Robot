# Pick and Place Robot Simulation | NVIDIA Isaac Sim + ROS 2

## Overview

This project demonstrates a robotic **Pick and Place application** developed using NVIDIA Isaac Sim and ROS 2. It features the **Franka Emika Panda robotic arm** operating in a simulated environment, exploring robotic manipulation, joint control, and communication between the simulation and ROS 2.

The objective is to simulate a robotic manipulation workflow in which a robot can interact with objects, pick them up, and place them at designated positions.

## Technologies Used

- NVIDIA Isaac Sim – Physics-based robotics simulation.
- ROS 2 – Robot Operating System for communication and control.
- Franka Emika Panda – 7-DOF robotic manipulator.
- USD (Universal Scene Description – 3D simulation environment and scene configuration.
- **Python** – Robotics scripting and integration.

## ⚙️ Project Features

- Franka Emika Panda robotic arm simulation.
- Pick and Place task environment.
- ROS 2 communication and joint-control integration.
- Physics-based robotic simulation.
- Exploration of robotic manipulation workflows.

## 🎯 Project Objective

To understand and implement the fundamentals of robotic manipulation by combining NVIDIA Isaac Sim's simulation capabilities with ROS 2 communication and control.
